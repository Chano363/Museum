## 核心组件详解

### App.vue - 主应用组件

主应用组件负责管理全局状态和视图切换。

**职责:**
- 管理当前视图状态（welcome/main）
- 存储展品数据列表
- 处理展品选择和切换
- 管理全局UI状态（设置面板、信息面板、手势提示）

**关键数据:**
```typescript
data() {
  return {
    currentView: 'welcome',           // 当前视图
    artifacts: [...],                  // 展品列表
    selectedArtifactIndex: 0,          // 当前选中展品索引
    showInfoPanel: false,              // 信息面板显示状态
    showGestureHint: false,            // 手势提示显示状态
    showSettings: false                // 设置面板显示状态
  }
}
```

**事件流:**
```
WelcomeView@enter → App.enterMuseum() → 切换到main视图
ThumbBar@select → App.selectArtifact() → 更新选中展品
MainView@showInfo → App.showArtifactInfo() → 显示信息面板
```

### MainView.vue - 主交互区

主交互区是用户与3D模型交互的核心区域。

**职责:**
- 渲染3D模型（使用 model-viewer）
- 管理摄像头显示状态
- 处理手势动作并控制模型
- 实现手指追踪功能

**模型控制方法:**
| 方法 | 功能 | 触发条件 |
|------|------|----------|
| `zoomIn()` | 放大模型 | 点赞手势 |
| `zoomOut()` | 缩小模型 | 点踩手势 |
| `resetModelView()` | 重置视图 | 手掌手势 |
| `onFingerMove()` | 旋转模型 | 手指追踪 |

**相机轨道控制:**
```javascript
// 相机轨道格式: "方位角 仰角 距离"
cameraOrbit = "0deg 75deg 0.5m"

// 放大: 减小距离
newDistance = currentDistance - 0.2

// 缩小: 增大距离
newDistance = currentDistance + 0.2
```

### GestureControl.vue - 手势控制组件

手势控制组件封装了摄像头捕获和手势识别逻辑。

**职责:**
- 初始化摄像头
- 捕获视频帧
- 调用手势识别服务
- 发出手势动作事件

**事件接口:**
```typescript
@action    // 识别到动作时触发
@gesture   // 检测到手势时触发
@finger-move  // 手指移动时触发
```

### ThumbBar.vue - 文物缩略图栏

显示所有展品的缩略图，支持点击切换。

**Props:**
```typescript
artifacts: Array<Artifact>    // 展品列表
selectedIndex: number         // 当前选中索引
```

**Events:**
```typescript
@select(index: number)        // 选择展品
```

### InfoPanel.vue - 文物详情浮层

展示当前选中文物的详细信息。

**显示内容:**
- 文物名称
- 朝代
- 详细描述

## 服务层架构

### GestureRecognitionService (前端ONNX)

基于 ONNX Runtime Web 的前端手势识别服务。

**初始化流程:**
```typescript
const service = new GestureRecognitionService()
await service.initialize(
  '/models/YOLOv10n_hands.onnx',    // 检测模型
  '/models/crops_classifier.onnx'   // 分类模型
)
```

**处理流程:**
```
ImageData → preprocessForDetection() → detectHands() 
         → extractHandCrop() → classifyGestures() → HandDetection[]
```

**预处理参数:**
```typescript
DETECTOR_SIZE = { width: 320, height: 240 }
CLASSIFIER_SIZE = { width: 128, height: 128 }
MEAN = [127, 127, 127]
STD = [128, 128, 128]
```

### BackendGestureRecognitionService

与后端API交互的手势识别服务。

**特点:**
- 自动降分辨率传输（320x240）
- 请求节流（最小间隔100ms）
- 连接超时处理（3秒）
- 自动重试机制

**请求格式:**
```typescript
POST /api/recognize
Content-Type: application/json

{
  "image": "data:image/jpeg;base64,..."  // Base64编码图像
}
```

### ActionRecognitionService

动作识别服务，将手势转换为具体操作。

**投票机制:**
```typescript
MAX_HISTORY_LENGTH = 50          // 最大历史记录数
STABILITY_THRESHOLD = 0.6        // 稳定性阈值
MIN_HISTORY_LENGTH_STATIC = 5    // 静态手势最小历史
MIN_HISTORY_LENGTH_DYNAMIC = 10  // 动态手势最小历史
```

**手势到动作映射:**
```typescript
const gestureToActionMap = {
  27: 'zoom_in',      // 点赞 → 放大
  24: 'zoom_out',     // 点踩 → 缩小
  31: 'rotate',       // 手掌 → 旋转
  19: 'rotate',       // 指向 → 旋转
  29: 'rotate',       // OK → 旋转
  25: 'switch',       // 拳头 → 切换
  0:  'switch_next',  // 右滑 → 下一件
  1:  'switch_prev'   // 左滑 → 上一件
}
```

## 性能优化

### 图像处理优化

1. **降分辨率传输**: 前端将图像降至320x240后发送
2. **请求节流**: 最小请求间隔100ms
3. **批量推理**: 多个裁剪区域合并为批次处理

### 模型加载优化

1. **懒加载**: 手势识别模型在需要时才加载
2. **缓存**: 模型加载后缓存在内存中
3. **CPU模式**: 使用CPU执行避免WASM初始化问题

### 渲染优化

1. **v-if条件渲染**: 按需渲染组件
2. **事件节流**: 手指移动事件限制在60fps
3. **CSS transform**: 使用transform进行动画
