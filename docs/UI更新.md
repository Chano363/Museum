# 主展示页面UI布局更新方案

## 一、核心设计思路

### 1. 视觉焦点放大
- **展品放大**：将3D模型展示区域作为视觉核心，增大模型尺寸，占据更多屏幕空间
- **沉浸式体验**：减少界面干扰元素，让用户注意力集中在文物本身

### 2. 信息布局优化

#### 左侧信息区重构
展品名称放大显示，使用书法风格字体，增强文化氛围，垂直顶满最左侧区域
- **垂直布局**：作者、年代等副信息采用垂直排列，形成视觉引导，使用Chill Hwo Kai字体
- **简洁呈现**：详情介绍区域采用极简线条分隔，保持视觉轻盈感

### 3. 界面简化
- **移除方框**：去掉框住物品的方框，让界面更通透
- **留白设计**：增加留白空间，提升整体视觉舒适度

## 二、字体风格统一

- **字体选择**：副信息和详细介绍采用两种粗细不同的同一款式字体
- **灵活调整**：可根据实际需求调整字体粗细，适配不同场景

## 三、交互体验优化

### 1. 模型交互
- **放大展示**：3D模型占据屏幕主要视觉区域
- **流畅操作**：保持手势控制的流畅性和精准度

### 2. 信息展示
- **层次分明**：通过字体大小和粗细区分信息层级
- **视觉引导**：垂直排列的信息形成自然的阅读顺序

## 四、视觉效果预期

1. **主次分明**：3D模型作为视觉主体，信息区域作为辅助
2. **文化氛围**：书法字体与文物展示相得益彰
3. **简洁优雅**：移除多余边框，界面更显轻盈
4. **沉浸式体验**：用户可专注于文物欣赏

## 五、实施步骤

1. 调整3D模型展示区域尺寸
2. 重构左侧信息区布局
3. 移除框住物品的方框元素
4. 统一字体风格和大小
5. 优化留白和间距

## 六、注意事项

- 保持功能完整性，不影响现有交互逻辑
- 确保在不同屏幕尺寸下的适配性
- 维持性能表现，避免因界面调整导致卡顿
