# 手势识别模块文档

## 模块概述

手势识别模块是系统的核心处理单元，负责实现手势识别的端到端处理流程。该模块采用多模型协同的方式，结合目标检测、图像分类和关键点追踪技术。

## 核心模型

### 1. YOLOv10n_hands.onnx - 手部检测模型

**用途:** 从图像中检测手部位置

**输入:**
- 尺寸: 640 × 640 × 3
- 格式: RGB
- 归一化: (pixel - 127) / 128

**输出:**
- 边界框: [x1, y1, x2, y2, confidence, ...]
- 置信度阈值: 0.4 (可配置)

**特点:**
- 基于YOLOv10n架构
- 专门针对手部检测优化
- 轻量级设计，适合实时应用

### 2. crops_classifier.onnx - 手势分类模型

**用途:** 识别裁剪图像中的手势类型

**输入:**
- 尺寸: 128 × 128 × 3
- 格式: RGB
- 归一化: (pixel - 127) / 128

**输出:**
- 类别数: 45种手势
- 格式: 概率分布

**特点:**
- 分类准确率高
- 支持45种手势识别
- 批量推理优化

### 3. hand_landmarker.task - 关键点检测模型

**用途:** 检测手部21个关键点位置

**输入:**
- 任意尺寸RGB图像
- 自动缩放处理

**输出:**
- 21个关键点坐标 (x, y, z)
- 归一化坐标

**关键点索引:**
```
0: 手腕 WRIST
1: 拇指CMC
2: 拇指MCP
3: 拇指IP
4: 拇指TIP
5: 食指MCP
6: 食指PIP
7: 食指DIP
8: 食指TIP ★ (用于手指追踪)
9: 中指MCP
10: 中指PIP
11: 中指DIP
12: 中指TIP
13: 无名指MCP
14: 无名指PIP
15: 无名指DIP
16: 无名指TIP
17: 小指MCP
18: 小指PIP
19: 小指DIP
20: 小指TIP
```

## 算法原理

### 手部检测算法 (YOLOv10n)

1. **图像预处理**
   - 将输入图像缩放到 640×640
   - RGB 通道归一化: `(pixel - 127) / 128`
   - 转换为 CHW 格式

2. **模型推理**
   - 使用 ONNX Runtime 执行推理
   - 支持 CPU/GPU/DirectML 加速

3. **后处理**
   - 过滤低置信度检测框 (阈值 0.4)
   - 返回边界框坐标和置信度

### 手势分类算法

1. **区域裁剪**
   - 将检测框扩展为正方形
   - 从原图裁剪手部区域

2. **图像预处理**
   - 缩放到 128×128
   - 归一化处理

3. **分类推理**
   - 输出 45 类手势概率
   - 取最大概率作为预测结果

### 手指追踪算法 (MediaPipe)

1. **关键点检测**
   - 检测 21 个手部关键点
   - 返回归一化坐标

2. **坐标转换**
   - 归一化坐标转像素坐标
   - 提取食指指尖位置

3. **移动计算**
   - 计算连续帧之间的位移
   - 用于模型旋转控制

## 动作识别服务

### 投票机制

为确保手势识别的稳定性，系统采用投票机制：

```typescript
class ActionRecognitionService {
  private gestureHistory: ActionType[] = []
  private readonly MAX_HISTORY_LENGTH = 30
  private readonly STABILITY_THRESHOLD = 0.5
  
  // 静态手势配置
  MIN_HISTORY_LENGTH_STATIC = 3
  STABILITY_THRESHOLD_STATIC = 0.5
  
  // 动态手势配置
  MIN_HISTORY_LENGTH_DYNAMIC = 5
  STABILITY_THRESHOLD_DYNAMIC = 0.45
}
```

### 稳定性计算

```typescript
// 统计历史记录中每个动作的出现次数
const actionCounts = {}
for (const action of this.gestureHistory) {
  actionCounts[action] = (actionCounts[action] || 0) + 1
}

// 计算稳定性
const stability = maxCount / this.gestureHistory.length

// 判断是否稳定
if (stability >= requiredStability) {
  return mostFrequentAction
}
```

## 环境变量配置

手势识别相关参数可通过环境变量配置：

| 变量名 | 默认值 | 说明 |
|--------|--------|------|
| `VITE_MAX_HISTORY_LENGTH` | 30 | 手势历史记录最大长度 |
| `VITE_STABILITY_THRESHOLD` | 0.5 | 手势稳定性阈值 |
| `VITE_MIN_HISTORY_LENGTH_STATIC` | 3 | 静态手势最小历史记录数 |
| `VITE_MIN_HISTORY_LENGTH_DYNAMIC` | 5 | 动态手势最小历史记录数 |
| `VITE_STABILITY_THRESHOLD_STATIC` | 0.5 | 静态手势稳定性阈值 |
| `VITE_STABILITY_THRESHOLD_DYNAMIC` | 0.45 | 动态手势稳定性阈值 |
| `CONFIDENCE_THRESHOLD` | 0.6 | 手势识别置信度阈值 |
| `DETECTION_CONFIDENCE_THRESHOLD` | 0.4 | 检测置信度阈值 |

## 性能调优建议

### 提高响应速度

1. **降低稳定性阈值**
   ```env
   VITE_STABILITY_THRESHOLD=0.4
   VITE_MIN_HISTORY_LENGTH_STATIC=2
   ```

2. **减少历史记录长度**
   ```env
   VITE_MAX_HISTORY_LENGTH=20
   ```

### 提高识别准确率

1. **提高稳定性阈值**
   ```env
   VITE_STABILITY_THRESHOLD=0.6
   VITE_MIN_HISTORY_LENGTH_STATIC=5
   ```

2. **增加历史记录长度**
   ```env
   VITE_MAX_HISTORY_LENGTH=40
   ```

   ```env
   VITE_IMAGE_WIDTH=240

   ```

2. **降低图像质量**
   ```env
   VITE_IMAGE_QUALITY=0.5
   ```

## 常见问题排查

### 1. 手势识别响应慢

**可能原因:**
- 后端服务未启动
- 网络延迟高
- 图像分辨率过高

**解决方案:**
- 检查后端服务状态
- 降低图像分辨率
- 检查网络连接

### 2. 手势识别不准确

**可能原因:**
- 光照条件差
- 手部距离摄像头太远/太近
- 背景复杂

**解决方案:**
- 改善光照条件
- 调整手部位置
- 简化背景

### 3. 手势识别抖动

**可能原因:**
- 稳定性阈值过低
- 历史记录长度过短

**解决方案:**
- 提高稳定性阈值
- 增加历史记录长度

### 4. 特定手势无法识别

**可能原因:**
- 手势不在支持列表中
- 手势角度不标准

**解决方案:**
- 参考支持的手势列表
- 调整手势角度
- 确保手部完整在画面中
