# 手势识别模块文档

## 模块概述

手势识别模块是系统的核心处理单元，负责实现手势识别的端到端处理流程。该模块采用多模型协同的方式，结合目标检测、图像分类和关键点追踪技术。

## 核心模型

### 1. YOLOv10n_hands.onnx - 手部检测模型

**用途:** 从图像中检测手部位置

**输入:**
- 尺寸: 640 × 640 × 3
- 格式: RGB
- 归一化: (pixel - 127) / 128

**输出:**
- 边界框: [x1, y1, x2, y2, confidence, ...]
- 置信度阈值: 0.4 (可配置)

**特点:**
- 基于YOLOv10n架构
- 专门针对手部检测优化
- 轻量级设计，适合实时应用

### 2. crops_classifier.onnx - 手势分类模型

**用途:** 识别裁剪图像中的手势类型

**输入:**
- 尺寸: 128 × 128 × 3
- 格式: RGB
- 归一化: (pixel - 127) / 128

**输出:**
- 类别数: 45种手势
- 格式: 概率分布

**特点:**
- 分类准确率高
- 支持45种手势识别
- 批量推理优化

### 3. hand_landmarker.task - 关键点检测模型

**用途:** 检测手部21个关键点位置

**输入:**
- 任意尺寸RGB图像
- 自动缩放处理

**输出:**
- 21个关键点坐标 (x, y, z)
- 归一化坐标

**关键点索引:**
```
0: 手腕 WRIST
1: 拇指CMC

9: 中指MCP
10: 中指PIP
```

### 手部验证

```typescript
const validateHandDetection = (detection: HandDetection): boolean => {
  const bbox = detection.bbox
  const width = bbox.x2 - bbox.x1
  const height = bbox.y2 - bbox.y1
  
  // 宽高比检查 (0.3-2)
  const aspectRatio = width / height
  if (aspectRatio < 0.3 || aspectRatio > 2) return false
  
  // 面积检查 (1000-100000)
  const area = width * height
  if (area < 1000 || area > 100000) return false
  
  return true
}
```

## OCSort 目标跟踪

### 概述

OCSort (Observation-Centric SORT) 是一种基于观测的目标跟踪算法，用于稳定跟踪手部位置。

### Kalman滤波器

```python
class KalmanFilter:
    """
    状态向量: [x, y, w, h, vx, vy, vw, vh]
    观测向量: [x, y, w, h]
    """
    
    def initiate(self, measurement):
        """初始化状态"""
        mean = np.r_[measurement, np.zeros(4)]
        covariance = np.diag([10, 10, 10, 10, 1e4, 1e4, 1e4, 1e4])
        return mean, covariance
    
    def predict(self, mean, covariance):
        """预测下一状态"""
        mean = np.dot(self._motion_mat, mean)
        covariance = np.linalg.multi_dot((
            self._motion_mat, covariance, self._motion_mat.T
        )) + self._motion_cov
        return mean, covariance
    
    def update(self, mean, covariance, measurement):
        """更新状态"""
        projected_mean = np.dot(self._update_mat, mean)
        projected_cov = np.linalg.multi_dot((
            self._update_mat, covariance, self._update_mat.T
        ))
        # Kalman增益计算...
        return new_mean, new_covariance
```

## 处理流程详解

### 完整识别流程

```
1. 图像捕获
   └── CameraView组件捕获视频帧

2. 数据传输
   └── 图像降分辨率 (320x240)
   └── Base64编码
   └── POST到 /api/recognize

3. 后端处理
   └── Base64解码
   └── OpenCV解码为numpy数组
   
4. 手部检测
   └── 图像预处理 (640x640, 归一化)
   └── YOLOv10n推理
   └── 过滤低置信度检测 (threshold=0.4)
   
5. 手势分类
   └── 边界框扩展为正方形
   └── 裁剪手部区域
   └── 图像预处理 (128x128, 归一化)
   └── crops_classifier推理
   └── argmax获取手势类别
   
6. 结果返回
   └── 过滤低置信度结果 (threshold=0.6)
   └── 映射手势名称
   └── 返回JSON响应

7. 前端处理
   └── ActionRecognitionService处理
   └── 投票机制确定动作
   └── 触发相应操作
```

### 手指追踪流程

```
1. 图像捕获 → MediaPipe处理
2. 提取食指指尖坐标 (关键点8)
3. 归一化坐标转像素坐标
4. 计算移动增量 (deltaX, deltaY)
5. 更新模型相机轨道
```
