# 博物馆文物展示系统技术路线文档

## 1. 项目概述

本项目是一个基于Web的博物馆文物展示系统，融合了现代前端技术与人工智能手势识别技术，为用户提供沉浸式的文物欣赏体验。系统通过摄像头实时捕捉用户手势，实现对3D文物模型的直观交互控制。

## 2. 技术栈选择

### 2.1 前端技术
- **框架**: Vue 3 + Vite
- **3D渲染**: Three.js、@google/model-viewer
- **手势识别**: TensorFlow.js、MediaPipe、ONNX Runtime Web
- **状态管理**: Vue 3 Composition API
- **样式**: 原生CSS3 + 自定义字体

### 2.2 后端技术
- **框架**: Flask (Python)
- **图像处理**: OpenCV
- **模型推理**: ONNX Runtime
- **API设计**: RESTful API
- **手势处理**: dynamic_gesture模块
  - 核心功能: 手部检测、手势分类、目标跟踪
  - 关键文件: onnx_models.py, main_controller.py
  - 依赖关系: 后端服务的核心处理模块

### 2.3 模型技术
- **手部检测**: YOLOv10n_hands.onnx
- **手势分类**: MobileNetV3_large.onnx、crops_classifier.onnx
- **模型格式**: ONNX (跨平台兼容)
- **模型存储**: dynamic_gestures/models文件夹
  - 包含所有核心模型文件
  - 模型加载路径: 后端服务从该文件夹加载模型
  - 模型管理: 集中管理，便于版本控制和更新

## 3. 系统架构

### 3.1 核心流程

1. **用户交互流程**:
   - 用户进入系统 → 欢迎页 → 主界面
   - 浏览文物 → 选择文物 → 查看3D模型
   - 执行手势 → 系统响应 → 模型交互

2. **手势识别流程**:
   - 摄像头捕获 → 前端处理 → 后端API调用 → dynamic_gesture处理
   - 结果返回 → 前端动作映射 → 执行操作

3. **模块关系**:
   - 前端负责用户界面和摄像头捕获
   - 后端提供API服务和模型调用
   - dynamic_gesture负责核心手势识别和处理

## 4. 核心功能模块

### 4.1 前端模块

#### 4.1.1 组件系统
- **WelcomeView**: 欢迎引导页，提供系统介绍和进入入口
- **MainView**: 主交互区，展示3D文物模型和处理用户交互
- **ThumbBar**: 文物缩略图栏，支持文物切换
- **GestureControl**: 手势控制核心组件，处理摄像头输入和手势识别
- **InfoPanel**: 文物详情浮层，展示文物信息
- **SettingView**: 设置面板，提供系统配置选项

#### 4.1.2 手势识别服务
- **GestureRecognitionService**: 基于ONNX模型的前端手势识别
- **MediaPipeHandTrackingService**: 基于MediaPipe的手部关键点跟踪
- **BackendGestureRecognitionService**: 与后端API交互的手势识别服务
- **TfjsGestureRecognitionService**: 基于TensorFlow.js的手势识别

#### 4.1.3 3D模型展示
- 使用@google/model-viewer展示GLTF格式的3D文物模型
- 支持模型旋转、缩放、平移等交互操作
- 响应式设计，适配不同屏幕尺寸

### 4.2 后端模块

#### 4.2.1 API服务
- **/api/recognize**: 接收前端发送的图像数据，返回手势识别结果
- 支持CORS跨域请求
- 错误处理和日志记录

#### 4.2.2 模型处理
- **HandDetection**: 基于YOLOv10n_hands模型的手部检测
- **HandClassification**: 基于crops_classifier模型的手势分类
- 图像处理和预处理功能

## 4.3 模型处理模块 (dynamic_gesture)

### 4.3.1 模块概述

model_gesture模块是整个系统的核心处理单元，负责实现手势识别的端到端处理流程。该模块集成了先进的计算机视觉技术和机器学习模型，为系统提供实时、准确的手势识别能力。

### 4.3.2 核心功能

1. **手部检测**
   - 基于YOLOv10n_hands模型的实时手部位置检测
   - 高精度边界框提取，支持复杂场景
   - 动态置信度调整，平衡准确率和召回率

2. **手势分类**
   - 使用crops_classifier模型识别45种不同手势
   - 支持one、point、like等核心交互手势
   - 正方形裁剪技术，提高分类准确率

3. **目标跟踪**
   - 采用OCSort算法实现手部轨迹的稳定跟踪
   - Kalman滤波器预测，实现平滑轨迹
   - 双轮关联机制，提高跟踪稳定性

4. **结果处理**
   - 标准化处理识别结果
   - 轨迹过滤和优化
   - 高效数据格式转换，返回给前端

### 4.3.3 技术优势

1. **性能优化**
   - 批量推理处理，提高识别速度
   - 多设备自适应，优先使用GPU加速
   - 内存管理优化，减少资源占用

2. **精度提升**
   - 多模型协同，提高识别准确率
   - 目标跟踪技术，减少误识别
   - 边界情况处理，提高鲁棒性

3. **可靠性设计**
   - 全面的异常处理机制
   - 空值检查和边界情况处理
   - 设备兼容性自动适配

### 4.3.4 核心流程

1. **图像捕获**: 前端摄像头实时捕获视频帧
2. **数据传输**: 通过RESTful API发送到后端
3. **预处理**: 颜色空间转换、尺寸调整、归一化
4. **手部检测**: YOLOv10n_hands模型检测手部位置
5. **手势分类**: crops_classifier模型识别具体手势
6. **目标跟踪**: OCSort算法跟踪手部轨迹
7. **结果处理**: 格式化处理，过滤无效结果
8. **返回结果**: 将识别结果返回给前端
9. **动作执行**: 前端根据识别结果执行相应操作

### 4.3.5 关键文件

- **onnx_models.py**: 模型加载和推理核心
- **main_controller.py**: 主控制器，实现目标跟踪
- **ocsort模块**: 目标跟踪算法实现
- **utils模块**: 工具函数和辅助方法

### 4.3.6 模型文件

- **YOLOv10n_hands.onnx**: 手部检测模型
- **crops_classifier.onnx**: 手势分类模型
- **MobileNetV3_large.onnx**: 备用手势分类模型
- **hand_detector.onnx**: 辅助手部检测模型
