一、总体风格
主色：宣纸米白 + 檀木深棕 + 朱砂点缀  
元素：简洁线条、现代几何造型、适度留白  
动效：淡入淡出、平滑过渡  

二、页面与模块拆分
1. 欢迎/引导页（WelcomeView）
   简洁背景，中央"探古"按钮  
   右下角"手势教学"入口  

2. 文物缩略图栏（ThumbBar）
   左上角横向排列，支持 3 件文物缩略图滑动  
   选中高亮：暗红描边 + 轻微放大  

3. 主交互区（MainView）
   背景：淡宣纸纹理，中央用于 3D 模型  
   手势热区：整屏（单摄像头）  
   底部工具栏：旋转锁定/自动旋转、放大/缩小、重置视角  

4. 文物详情浮层（InfoPanel）
   右侧弹出面板，含名称、朝代、简介、语音播放按钮  

5. 教学侧边栏（EduSidebar）
   教学场景可见，左侧竖向栏，可拖拽宽度  
   显示：坐标轴、尺寸标尺、网格开关  

6. 手势提示泡（GestureHint）
   半透明提示泡，跟随手部出现 1.5 s：  
     五指并拢向左/右滑动（用于切换模型）
     单指捏合（用于旋转模型）
     双手单指捏合并做出放大动作（用于缩放模型）

7. 设置页（SettingView）
   简洁现代样式，包含：摄像头状态、音量/亮度/自动休眠、关于&帮助  

三、网页技术栈
UI 框架：HTML5 + CSS3 + JavaScript  
3D 渲染：Three.js / Babylon.js  
手势识别：TensorFlow.js + MediaPipe Hands  
3D 控制：OrbitControls / ArcRotateCamera  
模型加载：GLTFLoader / OBJLoader  
语音播放：Web Audio API  
响应式设计：CSS Flexbox + Grid  

四、场景流程
WelcomeView → 点击"探古" → ThumbBar 滑入 → 点击缩略图 → 加载模型 → MainView 淡入 → 手势可用 → 详情/教学面板弹出  

五、性能与限制
单摄像头，手势模型依赖 RGB，识别距离 0.5–1.5 m  
模型三角面 <30 k，贴图 1 k，支持 LOD  
WebGL 渲染优化：减少 draw call，使用纹理图集  
响应式适配：支持桌面端和移动端  
浏览器兼容性：Chrome 90+、Firefox 88+、Safari 14+  

六、美术资源接口
1. 3D 模型格式：GLTF/GLB，包含基本材质  
2. 纹理资源：PNG/JPG，分辨率 1024x1024  
3. UI 素材：SVG/PNG，提供矢量和位图版本  
4. 音效资源：MP3/WAV，标准化音量  
5. 字体资源：提供 WebFont 链接或字体文件  
6. 色彩系统：提供 HEX/RGB 色值表  
7. 动画资源：提供关键帧数据或动画剪辑  

七、API 接口设计
1. 模型加载接口：支持从指定 URL 加载 3D 模型  
2. 手势识别接口：暴露手势事件和数据  
3. UI 控制接口：支持动态更新 UI 元素  
4. 配置管理接口：支持运行时修改配置参数  
5. 事件系统接口：支持自定义事件监听和触发
