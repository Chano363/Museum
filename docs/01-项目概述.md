# 探古 - 博物馆文物3D交互展示系统

## 项目简介

"探古"是一个融合现代前端技术与人工智能手势识别技术的博物馆文物3D交互展示系统。用户可以通过摄像头实时捕捉手势，实现对3D文物模型的直观交互控制，获得沉浸式的文物欣赏体验。

## 核心特性

- **沉浸式3D展示**: 使用 Google Model Viewer 展示 GLTF 格式的文物3D模型
- **手势交互**: 支持点赞、点踩、手掌旋转、滑动切换等手势操作
- **实时响应**: 基于摄像头的实时手势检测与模型控制
- **中国风UI**: 宣纸米白 + 檀木深棕 + 朱砂点缀的配色方案
- **响应式设计**: 适配桌面端和移动端
- **青铜器草图生图**: 支持用户绘制草图，AI 生成青铜器纹理

## 快速开始

> 详细的环境配置说明请参考 [开发环境配置指南](./development.md)

### 环境要求

- Node.js 20.19.5
- Python 3.13.5
- Conda (推荐)

### 安装步骤

1. **克隆项目**
```bash
git clone <repository-url>
cd Museum
```

2. **安装前端依赖**
```bash
npm install
```

3. **配置 Python 环境**
```bash
# 使用 Conda 创建环境
conda create -n dynamic python=3.13
conda activate dynamic

# 安装后端依赖
pip install -r backend/requirements.txt
```

4. **配置环境变量**
```bash
# 复制环境变量示例文件
cp .env.example .env

# 编辑 .env 文件，填写必要的配置
```

5. **启动开发服务器**
```bash
npm run start
```

这将同时启动前端开发服务器（端口3002）和后端API服务器（端口5000）。

### 单独启动

```bash
# 仅启动前端
npm run dev

# 仅启动后端
npm run backend
```
