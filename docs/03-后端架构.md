# 后端架构文档

## 架构概览

后端采用 Flask 框架构建，提供 RESTful API 接口。核心功能是手势识别服务，集成 ONNX Runtime 和 MediaPipe 进行模型推理。

```
┌─────────────────────────────────────────────────────────────┐
│                     Flask Application                        │
│  ┌──────────────────────────────────────────────────────┐   │
│  │                    Routes                             │   │
│  │  POST /api/recognize     - 手势识别                   │   │
│  │  POST /api/hand-tracking - 手部追踪                   │   │
│  └──────────────────────────────────────────────────────┘   │
│                          │                                   │
│                          ▼                                   │
│  ┌──────────────────────────────────────────────────────┐   │
│  │                  Model Layer                          │   │
│  │  ┌─────────────────┐  ┌─────────────────┐            │   │
│  │  │ HandDetection   │  │ HandClassification│            │   │
│  │  │ (YOLOv10n)      │  │ (crops_classifier)│            │   │
│  │  └─────────────────┘  └─────────────────┘            │   │
│  │  ┌─────────────────────────────────────┐              │   │
│  │  │ MediaPipe HandLandmarker            │              │   │
│  │  └─────────────────────────────────────┘              │   │
```

### API端点

#### POST /api/recognize

手势识别接口，返回检测到的手势信息。

**请求:**
```json
{
  "image": "data:image/jpeg;base64,..."
}
```

**响应:**
```json
{
  "detections": [
    {
      "bbox": {
        "x1": 100,
        "y1": 150,
        "x2": 200,
        "y2": 300,
        "confidence": 0.85
      },
      "gesture": 27,
      "gestureName": "like"
    }
  ]
}
```

**处理流程:**
```
Base64解码 → OpenCV解码 → 手部检测(YOLO) → 手势分类 → 过滤低置信度 → 返回结果
```

#### POST /api/hand-tracking

手部追踪接口，返回手部关键点位置。

**请求:**
```json
{
  "image": "data:image/jpeg;base64,..."
}
```

**响应:**
```json
{
  "success": true,
  "position": {
    "x": 320,
    "y": 240,
    "z": 0.5
  },
  "landmarks": [
    {"x": 100, "y": 200, "z": 0.1},
    // ... 21个关键点
  ]
}
```

**处理流程:**
```
Base64解码 → MediaPipe处理 → 提取关键点 → 返回结果
         ↓ (失败时)
         ONNX回退检测 → 返回边界框中心
```

## ONNX 模型层 (onnx_models.py)

### 基类 OnnxModel

所有ONNX模型的基类，提供通用功能。

```python
class OnnxModel(ABC):
    def __init__(self, model_path, image_size):
        self.model_path = model_path
        self.image_size = image_size
        self.mean = np.array([127, 127, 127], dtype=np.float32)
        self.std = np.array([128, 128, 128], dtype=np.float32)
        # 初始化ONNX会话
        self.sess = ort.InferenceSession(model_path, ...)
```

**预处理方法:**
```python
def preprocess(self, frame):
    # 1. BGR转RGB
    image = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
    # 2. 调整尺寸
    image = cv2.resize(image, self.image_size)
    # 3. 归一化
    image = (image - self.mean) / self.std
    # 4. 转换维度顺序 (HWC -> CHW)
    image = np.transpose(image, [2, 0, 1])
    # 5. 添加批次维度
    image = np.expand_dims(image, axis=0)
    return image
```

**执行提供者选择:**
```python
@staticmethod
def get_onnx_provider():
    device = ort.get_device()
    providers = []
    
    # 优先使用GPU
    if "GPU" in device:
        providers.append("CUDAExecutionProvider")
    elif "DML" in device:
        providers.append("DmlExecutionProvider")  # DirectML
    
    # CPU作为后备
    providers.append("CPUExecutionProvider")
    return providers
```

### HandDetection 类

手部检测模型，基于YOLOv10n。

```python
class HandDetection(OnnxModel):
    def __init__(self, model_path, image_size=(640, 640), confidence_threshold=0.5):
        super().__init__(model_path, image_size)
        self.confidence_threshold = confidence_threshold
    
    def __call__(self, frame):
        # 1. 预处理
        input_tensor = self.preprocess(frame)
        
        # 2. 模型推理
        results = self.sess.run(self.output_names, {self.input_name: input_tensor})
        
        # 3. 解析输出
        detections = results[0][0]
        
        # 4. 过滤低置信度
        valid_detections = detections[detections[:, 4] > self.confidence_threshold]
        
        # 5. 提取边界框和概率
        boxes = valid_detections[:, :4]
        probs = valid_detections[:, 4]
        
        # 6. 缩放到原始图像尺寸
        boxes *= [scale_x, scale_y, scale_x, scale_y]
        
        return boxes.astype(np.int32), probs
```

### HandClassification 类

手势分类模型，识别45种手势。

```python
class HandClassification(OnnxModel):
    def __init__(self, model_path, image_size=(128, 128)):
        super().__init__(model_path, image_size)
    
    def __call__(self, image, bboxes):
        # 1. 获取正方形裁剪区域
        crops = self.get_crops(image, bboxes)
        
        # 2. 批量预处理
        processed_crops = [self.preprocess(crop) for crop in crops if crop is not None]
        
        # 3. 合并批次
        concatenated_crops = np.concatenate(processed_crops, axis=0)
        
        # 4. 批量推理
        outputs = self.sess.run(None, {input_name: concatenated_crops})[0]
        
        # 5. 获取预测类别
        labels = np.argmax(outputs, axis=1)
        
        return labels.tolist()
```

**正方形裁剪:**
```python
@staticmethod
def get_square(box, image):
    """将边界框扩展为正方形"""
    x0, y0, x1, y1 = box
    w, h = x1 - x0, y1 - y0
    
    # 扩展为正方形
    if h < w:
        y0 = y0 - int((w - h) / 2)
        y1 = y0 + w
    if h > w:
        x0 = x0 - int((h - w) / 2)
        x1 = x0 + h
    
    # 边界检查
    x0, y0 = max(0, x0), max(0, y0)
    x1, y1 = min(width-1, x1), min(height-1, y1)
    
    return x0, y0, x1, y1
```
