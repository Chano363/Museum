# 开发指南

## 环境搭建

### 系统要求

- **操作系统:** Windows 10/11, macOS, Linux
- **Node.js:** >= 16.0.0
- **Python:** >= 3.9
- **Conda:** 推荐 (用于Python环境管理)

### 安装步骤

#### 1. 克隆项目

```bash
git clone <repository-url>
cd Museum
```

#### 2. 安装前端依赖

```bash
npm install
```

#### 3. 配置Python环境

**使用Conda (推荐):**

```bash
conda env create -f environment.yml
conda activate museum-env
```

**使用pip:**

```bash
pip install -r dynamic_gestures/requirements.txt
pip install flask flask-cors
```

#### 4. 下载模型文件

模型文件应放置在以下位置：

```
dynamic_gestures/models/
├── YOLOv10n_hands.onnx
├── crops_classifier.onnx
└── MobileNetV3_large.onnx

models/
└── hand_landmarker.task
```

MediaPipe模型会自动下载。

### 启动开发服务器

**同时启动前后端:**

```bash
npm run start
```

**单独启动:**

```bash
# 前端 (端口3002)
npm run dev

# 后端 (端口5000)
npm run backend
```

## 常见问题

### 1. 模型加载失败

**问题:** 前端无法加载ONNX模型

**解决方案:**
- 检查模型文件路径是否正确
- 确保模型文件在 `public/models/` 目录
- 检查浏览器控制台错误信息

### 2. 后端连接失败

**问题:** 前端无法连接后端API

**解决方案:**
- 确认后端服务已启动 (端口5000)
- 检查Vite代理配置
- 检查防火墙设置

### 3. 手势识别不准确

**问题:** 手势识别结果不稳定

**解决方案:**
- 调整置信度阈值
- 增加投票历史长度
- 改善光照条件
- 确保手部在画面中清晰可见

### 4. 3D模型加载失败

**问题:** model-viewer无法加载模型

**解决方案:**
- 检查GLTF文件路径
- 确保模型文件完整
- 检查浏览器控制台错误
- 验证模型格式是否正确

## 常见问题 FAQ

### Q1: 如何修改前端端口？

**A:** 在 `.env` 文件中设置：
```env
VITE_PORT=3003
```

### Q2: 如何更换 Conda 环境名称？

**A:** 在 `.env` 文件中设置：
```env
CONDA_ENV_NAME=my-env
```

### Q3: 手势识别不准确怎么办？

**A:** 
1. 确保光照充足
2. 调整稳定性阈值：`VITE_STABILITY_THRESHOLD=0.6`
3. 增加历史记录长度：`VITE_MAX_HISTORY_LENGTH=40`

### Q4: 后端启动失败怎么办？

**A:** 
1. 检查 Python 版本是否 >= 3.9
2. 确认依赖已安装：`pip install -r backend/requirements.txt`
3. 检查模型文件是否存在

### Q5: 如何启用 GPU 加速？

**A:** 
1. 安装 CUDA 工具包
2. 安装 onnxruntime-gpu：`pip install onnxruntime-gpu`
3. 系统会自动检测并使用 GPU

### Q6: 前端构建失败怎么办？

**A:** 
1. 清除缓存：`npm cache clean --force`
2. 删除 node_modules 目录
3. 重新安装：`npm install`

### Q7: 如何添加新的手势？

**A:** 参考 [添加新手势](#添加新手势) 章节，需要：
1. 更新类型定义
2. 更新后端映射
3. 添加动作映射
4. 实现动作处理

### Q8: 如何调试手势识别？

**A:** 
1. 打开浏览器开发者工具
2. 查看控制台日志
3. 使用 Vue Devtools 查看组件状态
4. 点击工具栏 📋 按钮导出日志

### Q9: 生产环境如何部署？

**A:** 
1. 构建前端：`npm run build`
2. 使用 gunicorn 或 waitress 部署后端
3. 配置 HTTPS 和反向代理
4. 限制 CORS 来源

### Q10: 如何配置 AI 生图功能？

**A:** 
1. 注册即梦账号（注册后赠送 200 次生图次数）：https://console.volcengine.com/ark
2. 创建 API Key
3. 在 `.env` 中配置

```env
AI_PROVIDER=jimeng
ARK_API_KEY=你的API密钥
JIMENG_MODEL=doubao-seedream-4-5-251128
```
